# GitHub Pages 部署步骤（网页操作，不用命令行）

目的：把看板放到网上，得到一个网址，发给同事打开就能看（含访问密码门）。

## 第 1 步：注册/登录 GitHub
1. 打开 https://github.com 注册账号（免费），或直接登录已有账号。

## 第 2 步：新建仓库（Repository）
1. 登录后点右上角 + 号 → New repository
2. Repository name 随便填，比如 tiktok-dashboard
3. 必须选 Public（公开，免费版网页只能用公开仓库）
4. 其他保持默认 → Create repository

## 第 3 步：上传看板文件
1. 进入刚建的仓库页面，点 “uploading an existing file”（上传已有文件）
2. 把「看板分享包」文件夹里的 7 个文件全部拖进去：
   index.html、app.js、style.css、echarts.min.js、data.js、detail-data.js、使用说明.txt
   （注意：是文件直接上传，不要整个文件夹）
3. 点 Commit changes 提交

## 第 4 步：开启网页（GitHub Pages）
1. 仓库页面点 Settings（设置）
2. 左侧菜单找到 Pages
3. Source 选 Deploy from a branch，Branch 选 main，点 Save
4. 等 1-2 分钟，页面会显示网址：https://你的用户名.github.io/tiktok-dashboard/
5. 用浏览器打开验证，输入密码进入看板

## 第 5 步：分享
- 把网址 + 访问密码发给同事（默认密码 tiktok2026，可在看板「配置」里修改）
- 以后更新：把新文件重新上传到同一个仓库（网页直接拖拽覆盖），等 1-2 分钟刷新网址即最新

## 注意事项
- 免费 GitHub Pages 是公开仓库：拿到网址就能访问，密码门只是防误开/防随手转发，不是绝对安全。
- 看板里是经营数据，建议只发给信任的人。
